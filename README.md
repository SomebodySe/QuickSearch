# QuickSearch
## 就是个快速往搜索框填东西的小工具！
上班用的公司软件没有筛选功能，每次在几千个信号里面挑出信号按顺序排列，上下翻找很费劲！不停改搜索框的内容又很麻烦！所以我就做了这个工具，快速替换搜索框的内容，也算是筛选功能了！
## 使用方法
打开程序后点复位回出现一个红点，把这个红点拖到输入框里面，然后点击按钮就能把按钮里面的内容填到输入框了！具体实现方式就是模拟鼠标点击红点位置，然后把按钮里面的文本粘贴到当前正在活动的输入框！  
  
右键点击按钮修改按钮内容，可以设置为空；   
点击+—号修改按钮数量；   
勾选自动Enter，输入内容后就会自动按回车；  
点击复位把红点放回右边的方框里面。
